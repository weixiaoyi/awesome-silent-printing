# Contributing

Thanks for improving this list.

**English** | [中文](CONTRIBUTING.zh-CN.md)

## Add a tool

1. Use this format:

   ```md
   - [Name](https://example.com/) — One factual sentence. Note OS / license / hardware limits if important.
   ```

2. Put it in the most relevant section (or propose a new section).
3. Prefer primary docs / official repos over mirror pages.
4. No marketing fluff, paid placement, or unverifiable claims.
5. After changing tool entries, update **all completed language READMEs** (at minimum `README.md` and `README.zh-CN.md`). Leave placeholders alone unless you are finishing that language.

## Translations

We aim to support language switching for:

English · 中文 · 日本語 · Español · Português (Brasil) · 한국어 · Deutsch · Русский

See [TODO.md](TODO.md). When finishing a language:

1. Replace the placeholder README with a full translation aligned to `README.md`.
2. Mark the language **Done** in the Translations table on every README.
3. Check the matching box in `TODO.md`.

## Naming

Always write the product as **`web-print-pdf (Web Print Expert)`** (Chinese docs: `web-print-pdf（Web Print Expert）`).

## Pull requests

- Keep descriptions short and neutral.
- One logical change per PR when possible.
- Fix dead links whenever you spot them.
