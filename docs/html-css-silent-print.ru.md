# Тихая печать с HTML/CSS

## Зачем командам это нужно

Большинство бизнес-UI уже на HTML/CSS. Если тихая печать переиспользует те же шаблоны, frontend остаётся быстрым, и не нужно поддерживать второй набор навыков ZPL/ESC/POS для каждого счёта.

## Две модели вёрстки

| Модель | Плюсы | Минусы |
|---|---|---|
| HTML/CSS через локальный Chromium/агент | Привычно веб-командам; хорошая точность | Нужен локальный агент |
| Raw ESC/POS / ZPL | Точный контроль устройства | Другой skill set; привязка к железу |

Многие продукты смешивают: A4 в HTML, термочеки в raw.

## Что здесь значит «print CSS»

Браузерный `@media print` сам по себе **не** тихий путь — всё равно через `window.print()`. С локальным агентом обычно:

1. Собираете самодостаточную HTML-строку (или URL).
2. Подключаете CSS, который нужен агенту (inline, абсолютный URL или bundle).
3. Передаёте размер бумаги / поля / имя принтера в опциях SDK.
4. Движок агента (часто Chromium) пагинирует и отправляет в спулер.

### Чеклист шаблона

- [ ] Явный размер страницы (A4, 100×150 мм, рулон 80 мм, …)
- [ ] Поля под физический носитель
- [ ] Шрифты на рабочей станции или embedded
- [ ] Штрихкод/QR как SVG или высокое разрешение (проверить скан)
- [ ] Таблицы без обрезки последней строки
- [ ] Без зависимости от viewport-only (`100vh` ловушки)

## Практические советы

- Отдельная **print-only** таблица стилей; не копируйте слепо CSS всего приложения.
- Для этикеток предпочитайте `mm` / `in`; один `px` плывёт между DPI.
- Тестируйте CJK на Windows **и** Linux, если поддерживаете обе ОС.
- Один preview-задание перед включением пакета при миграции шаблонов.
- Держите картинки компактными; огромные PNG убивают throughput пакета.
- Для точных резаков / денежных ящиков может понадобиться raw на raw-capable мосте.

## Хорошо подходит

Счета, выписки, упаковочные листы, A4-отчёты, многие этикетки, отрендеренные как HTML.

## Слабо подходит (raw / SDK производителя)

- Очень быстрые кухонные принтеры только под ESC/POS
- Парки Zebra со стандартизированными ZPL в прошивке
- Устройства без нормального драйвера Win/macOS/Linux, кроме vendor raw
