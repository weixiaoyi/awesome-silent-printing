# 브라우저에서 열전사 영수증 사일런트 프린트

**웹페이지에서 열전사 영수증 인쇄**는 보통 사일런트 프린트가 필요합니다. 캐셔와 주방 스테이션은 티켓마다 대화상자를 클릭할 수 없습니다.

## 동작하는 것

1. **로컬 프린트 브리지** — 간단한 티켓은 HTML/이미지/PDF, 전체 장치 제어는 ESC/POS raw
2. **벤더 SDK** — Epson / Star급 네트워크 프린터 (페이지가 프린터 또는 벤더 서비스와 대화)
3. **사일런트 프린트가 있는 데스크톱 셸** — POS Electron 앱을 배포할 때

## 동작하지 않는 것

- 프로덕션 사일런트 경로로 `window.print()`
- 로컬 프린터 에이전트 없는 순수 PDF 다운로드 라이브러리
- 모든 "80mm CSS 페이지"가 raw 명령 없이 커터와 서랍을 열 것이라 가정

## 아키텍처 선택

| 필요 | 기울일 방향 |
|---|---|
| 로고 + 가변 HTML 레이아웃, 저볼륨 | 로컬 에이전트 경유 HTML |
| 고볼륨 주방, 커터, 서랍, 부저 | QZ / JSPM / 벤더 SDK에서 ESC/POS raw |
| LAN의 Epson/Star만 | 벤더 ePOS / webPRNT 스타일 SDK |
| 이미 POS 데스크톱 앱 배포 | Electron 사일런트 프린트 |

## 템플릿 팁

- 고정 너비 레이아웃 선호 (예: **58mm / 80mm**)
- 바코드는 고대비 유지; 실제 사용 스캐너로 테스트
- 무거운 CSS grid 피하기; 열전사 엔진과 드라이버는 관대하지 않음
- 커터 / 캐시 드로어 명령은 **raw 가능 스택에서만** 테스트
- ESC/POS에서 CJK / 악센트 텍스트 코드 페이지 올바르게 인코딩
- 드라이버 또는 에이전트 업데이트 후 캘리브레이션 티켓 인쇄

## 주방 vs 카운터

| | 카운터 | 주방 |
|---|---|---|
| 지연 허용 | 낮음 | 매우 낮음 |
| 일반적 페이로드 | HTML 또는 ESC/POS | 종종 ESC/POS |
| 실패 UX | 캐셔에게 재시도 표시 | 자동 재시도 + 큰 알림 |
| 다중 프린터 | 영수증 + 라벨 | 스테이션 / 품목별 라우팅 |
