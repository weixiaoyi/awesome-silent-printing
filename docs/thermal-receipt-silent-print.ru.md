# Тихая печать термочеков из браузера

**Печать термочеков со страницы** обычно требует тихой печати: кассиры и кухня не могут кликать диалог на каждом тикете.

## Что работает

1. **Локальный мост печати** — HTML/image/PDF для простых чеков или ESC/POS raw для полного контроля устройства
2. **SDK производителя** для сетевых Epson / Star (страница говорит с принтером или сервисом vendor)
3. **Десктопная оболочка** с тихой печатью, если вы поставляете POS на Electron

## Что не работает

- `window.print()` как продакшен-путь тихой печати
- Чистые PDF download-библиотеки без локального агента принтера
- Допущение, что любая «80mm CSS-страница» отрежет и откроет ящик без raw-команд

## Выбор архитектуры

| Потребность | Склоняться к |
|---|---|
| Логотип + переменная HTML-вёрстка, низкий объём | HTML через локальный агент |
| Высокий объём кухни, резак, ящик, зуммер | ESC/POS raw на QZ / JSPM / SDK производителя |
| Только Epson/Star в LAN | Vendor ePOS / webPRNT SDK |
| Уже есть POS desktop app | Electron silent print |

## Советы по шаблонам

- Фиксированная ширина (например **58mm / 80mm**)
- Штрихкоды с высоким контрастом; тест с вашим сканером
- Без тяжёлых CSS grid; термодвижки и драйверы не прощают
- Команды резака / денежного ящика **только** на raw-capable стеках
- Правильные code pages для CJK / акцентов на ESC/POS
- Калибровочный чек после обновления драйвера или агента

## Касса vs кухня

| | Касса | Кухня |
|---|---|---|
| Допуск по задержке | Низкий | Очень низкий |
| Типичный payload | HTML или ESC/POS | Часто ESC/POS |
| UX при сбое | Retry кассиру | Auto-retry + громкий алерт |
| Несколько принтеров | Чек + этикетка | Маршрут по станции / позиции |
